Bettee Way Creator

面向 Bettee Way 美妆个护业务的内部短视频内容工具。通过 TikTok Content Posting API，将成片上传至已授权 TikTok 账号的草稿箱，供人工复核后发布。

→ 进入上传工具

这个工具做什么

① 上传成片到草稿箱

调用 Content Posting API 的 video.upload，将本地成片传入授权账号的草稿箱（SELF_ONLY），不会自动对外发布。

② 人工复核后发布

团队在 TikTok 应用内查看草稿、确认品牌与价格无误后手动发布；如需 API 直发，使用 video.publish。

③ 内容合规自检

上传前核对封面取自真实视频帧、品牌名与所挂商品一致、价格与定价表一致，避免货不对板与虚假宣称。

端到端流程

  1. 授权 TikTok 账号通过 TikTok 官方授权流程，将目标创作者账号授权给本应用。
  2. 选择成片在本工具界面选择已通过质检的 mp4 视频文件。
  3. 上传到草稿箱调用 video.upload，视频进入该账号草稿箱。
  4. 人工复核在 TikTok 应用内查看成片，确认品牌、价格、文案无误。
  5. 发布人工点击发布，或调用 video.publish 完成发布。

关于数据：本服务仅上传本企业自有素材，不接入 Display API，不读取、不存储任何 TikTok 端用户的个人资料或粉丝数据。

关于发布：所有视频默认进入草稿箱，经人工复核后发布；本服务不会自动对外发布内容。
