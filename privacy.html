隐私政策 Privacy Policy

Bettee Way Creator · 生效日期：2026 年 10 月 3 日

本隐私政策说明 Bettee Way Creator（"本服务"）如何收集、使用、存储与保护用户信息。本服务由 Bettee Way（"我们"）运营。

一、我们收集哪些信息

信息类型具体内容收集方式
账号信息企业分配的账号标识、访问凭据您登录本服务时提供
授权信息您授权的 TikTok 账号标识、Content Posting API 的访问令牌（access token）与刷新令牌（refresh token）您通过 TikTok 官方授权流程授予
内容数据您上传的视频文件及其标题、描述、所关联的商品信息您主动上传
技术信息操作日志（上传时间、文件标识、处理状态）、IP 地址、浏览器类型系统自动记录

我们不收集：通讯录、相册中与业务无关的照片、通讯记录、位置信息、生物识别信息，亦不收集任何 TikTok 用户的个人数据。本服务不调用 Display API，不读取、不存储、不分析任何 TikTok 端用户的资料、粉丝数据或视频数据。

二、我们如何使用这些信息

  • 执行您的上传指令，将视频传输至您授权的 TikTok 账号草稿箱；
  • 维护与刷新 Content Posting API 所需的访问授权；
  • 记录操作日志，用于故障排查、服务安全与合规审计；
  • 履行法定的信息留存与配合调查义务。

我们不会将上述信息出售、出租或以其他方式提供给第三方用于广告目的。

三、信息的存储与保护

  • 存储位置：访问令牌与业务日志存储于我们自有服务器，数据存储区域位于中华人民共和国境内。
  • 传输安全：本服务与 TikTok 官方 API 之间的所有通信均使用 HTTPS 加密；访问令牌不以明文形式存储或展示。
  • 访问控制：仅经授权的企业内部人员可在必要范围内访问本服务；每次访问均留有审计记录。
  • 保留期限：操作日志保留至服务终止后 12 个月；访问令牌在您撤销 TikTok 授权或服务终止时立即删除。

四、Cookie 与本地存储

本服务仅使用维持登录状态所必需的技术性 Cookie 及本地存储项（如会话标识），不使用广告追踪、行为分析或第三方 Cookie。禁用这些 Cookie 将导致无法保持登录状态。

五、第三方服务

本服务在必要范围内会与 TikTok 官方服务交互。当您授权本服务访问您的 TikTok 账号时，视频内容将传输至 TikTok 平台，其后续的数据处理适用 TikTok 自身的隐私政策。除该必要交互外，本服务不接入任何其他第三方服务。

六、您的权利

在法律允许的范围内，您有权查询、更正、删除您的个人信息，或撤回对本服务的授权。您可随时在 TikTok 应用的设置中撤销对本应用的授权；撤销后我们将同步删除对应令牌。本服务为内部工具，如需行使上述权利，请通过 Bettee Way 官方店铺客服渠道与我们联系，我们将在收到请求后 15 个工作日内处理。

七、未成年人保护

本服务不面向未成年人开放，我们不会有意收集未成年人的个人信息。

八、政策更新

本政策如有变更，我们将在本页面更新并标注新的生效日期，继续使用本服务即视为接受更新后的政策。

九、联系我们

如您对本隐私政策有任何疑问或意见，请通过 Bettee Way 官方店铺客服渠道与我们联系。
